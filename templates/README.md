Email Templates
===============

This directory contains all email templates used by ngenCerf.

Directory Structure
-------------------

templates/djoser/email/
    activation.html
    activation.txt
    password_reset.html
    password_reset.txt

templates/email/
    verify_email.html
    verify_email.txt


Template Usage
--------------

templates/djoser/email/activation.*
    Used by Djoser when a new user registers and receives the initial
    account activation email.

    Triggered by:
        POST /auth/users/

    The email contains a link that directs the user to the frontend
    activation page defined by:

        DJOSER["ACTIVATION_URL"]


templates/djoser/email/password_reset.*
    Used by Djoser when a user requests a password reset.

    Triggered by:
        POST /auth/users/reset_password/

    The email contains a link that directs the user to the frontend
    password reset page defined by:

        DJOSER["PASSWORD_RESET_CONFIRM_URL"]


templates/email/verify_email.*
    Used by the custom ngenCerf endpoint for sending verification emails.

    Triggered by:
        POST /auth/users/send_verification_email/

    This email is used when:
        * a user resends a verification email
        * a user changes their email address and must verify the new address


Notes
-----

Activation and password reset emails are generated by Djoser and use the
templates located under:

    templates/djoser/email/

Custom verification emails are generated by:

    calibration.views.email_verification_views.send_verification_email()

and use the templates located under:

    templates/email/
