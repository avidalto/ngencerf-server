Email Templates
===============

This directory contains all email templates used by ngenCerf.

Directory Structure
-------------------

templates/email/
    password_reset.html
    verify_email.html
    verify_email.txt


Template Usage
--------------

templates/email/password_reset.html
    Used by Djoser when a user requests a password reset.

    Triggered by:
        POST /auth/users/reset_password/

    The email contains a link that directs the user to the shared
    frontend login page using:

        /login?action=reset-password&uid=<uid>&token=<token>

    The exact path/query string is defined by:

        DJOSER["PASSWORD_RESET_CONFIRM_URL"]

    Unlike the verification templates, this file must use the
    block-based format expected by Djoser:

        {% block subject %}
        {% block text_body %}
        {% block html_body %}

    Djoser extracts these blocks to construct the email subject,
    plain-text body, and HTML body.


templates/email/verify_email.*
    Used by the custom ngenCerf endpoint for sending verification emails.

    Triggered by:

        Initial registration:
            POST /auth/users/

        Resend verification email:
            POST /auth/users/send_verification_email/

        Change email address and verify the new address:
            POST /auth/users/send_verification_email/

    The email contains a link that directs the user to the shared
    frontend login page using:

        /login?action=verify-email&token=<token>

    These templates are rendered directly by Django using:

        render_to_string("email/verify_email.txt", context)
        render_to_string("email/verify_email.html", context)


Notes
-----

All email templates are located under:

    templates/email/

Password reset emails are generated by Djoser and use the block-based
template format described above.

Verification emails are generated by ngenCerf and are sent by:

    calibration.views.email_verification_views.send_initial_verification_email()
    calibration.views.email_verification_views.send_verification_email()

Because the verification emails are rendered manually with
`render_to_string`, they use separate `.html` and `.txt` templates,
while the Djoser password reset email uses a single template file
containing subject/text/html blocks.
